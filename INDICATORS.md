# Indicator and formula conventions

Reference concepts are catalogued by StockCharts (S02); the following implementation choices remove library-to-library ambiguity. They are binding for this specification bundle and are not claims that the source prescribes every choice. Periods are bars unless explicitly months/weeks. Read EXECUTION.md for lag and warm-up rules.

## Primitive operations
- r=C/C[1]-1 is decimal simple return; log return=ln(C/C[1]); ROC(n)=100*(C/C[n]-1) in percentage points. Percent thresholds include their units. In portfolio return/volatility scores convert ROC to decimal before division. Std is population std (ddof=0); covariance uses unbiased sample covariance (ddof=1). Z(X,n)=(X-SMA(X,n))/Std(X,n) includes current bar unless explicitly lagged. A prior-window z instead uses mean/std from t-n..t-1. Skip zero std.
- HH(X,n), LL(X,n): rolling maximum/minimum of X; HH(H,n) uses high, HH(C,n) uses close. SMA(n) without series means mean close. EMA uses alpha=2/(n+1), initialized at SMA of first n valid values. Wilder RMA uses alpha=1/n, SMA seed. WMA uses linearly increasing weights 1..n from oldest to newest.
- PR(X,n)=100*(count(prior n X values strictly less than X[t])+0.5*count(equal))/n; exclude t from reference distribution. Rolling quantile uses NumPy linear interpolation over stated preceding window. A comparison to a percentile uses the historical values only.
- CLV01=(C-L)/(H-L); if H=L set 0.5. Body and wick formulas are given in the relevant rule. TR=max(H-L,abs(H-C[1]),abs(L-C[1])); ATR(n)=RMA(TR,n). ATR(14) in risk overlays is fixed, not an extra hidden optimized parameter.
- Daily volatility=Std(decimal simple daily returns,n). Annualized volatility uses sqrt(252) for US securities and sqrt(365) for crypto. Total return includes reinvested distributions. Excess ROC is asset percentage total return minus compounded cash percentage return over the same completed interval.

## Trend and momentum
- RSI(n): 100-100/(1+RS); RS=RMA(max(deltaC,0),n)/RMA(max(-deltaC,0),n). If both averages zero set RSI=50; zero losses only =>100; zero gains only=>0. Apply same formula to ratio or streak series when specified.
- MACD(f,s)=EMA(C,f)-EMA(C,s); signal=EMA(MACD,q); MACDhist=MACD-signal. PPO(f,s)=100*(EMA(C,f)-EMA(C,s))/EMA(C,s). PVO is PPO on volume.
- SlowK(n,s)=SMA(100*(C-LL(L,n))/(HH(H,n)-LL(L,n)),s). SlowD(n,s,d)=SMA(SlowK,d). Equal rolling high/low => raw stochastic=50. StochRSI(n)=(RSI(n)-LL(RSI(n),n))/(HH(RSI(n),n)-LL(RSI(n),n)); scale 0..1, no additional smoothing, flat denominator=>0.5. WilliamsR(n)=-100*(HH(H,n)-C)/(HH(H,n)-LL(L,n)); flat denominator=>-50.
- CCI(n)=(TP-SMA(TP,n))/(0.015*mean(abs(TP_i-current_window_mean_TP))), TP=(H+L+C)/3; flat mean deviation=>0. Weekly CCI uses completed weekly OHLC.
- DI/ADX(n): up=H-H[1], down=L[1]-L; +DM=up if up>down and up>0 else 0; -DM=down if down>up and down>0 else 0. DIplus=100*RMA(+DM,n)/ATR(n), similarly DIminus. DX=100*abs(DIplus-DIminus)/(DIplus+DIminus); ADX=RMA(DX,n). Flat denominators=>0.
- Aroon(n): examine n+1 bars; AroonUp=100*(n-bars_since_highest_high)/n, AroonDown analogous lowest low; ties choose most recent extreme. VIplus(n)=sum(abs(H-L[1]),n)/sum(TR,n), VIminus=sum(abs(L-H[1]),n)/sum(TR,n).
- TRIX(n)=100*ROC_decimal_of_one_bar(EMA(EMA(EMA(C,n),n),n)). TSI(long,short)=100*EMA(EMA(deltaC,long),short)/EMA(EMA(abs(deltaC),long),short). Zero denominator=>0.
- KST: SMA(ROC(10),10)+2*SMA(ROC(15),10)+3*SMA(ROC(20),10)+4*SMA(ROC(30),15). The supplied strategy uses SMA(KST,signal) as its signal line.
- ConnorsRSI(3,2,100)=mean(RSI(C,3), RSI(streak,2), PR(ROC(1),100)). Streak starts at 0, increments positive run by 1 on higher close, decrements negative run by 1 on lower close, resets to +1/-1 on direction change and 0 on unchanged close.
- OLS log-price regression uses intercept and time indices 0..n-1 on formation sample, extrapolated at index n for the next observation. Population residual std is sqrt(mean(residual^2)) after intercept fit. R2=1-SSE/SST; skip SST=0.

## Bands and volume
- BB(n,k): mid=SMA(C,n); upper/lower=mid +/- k*Std(C,n). BBWidth=100*(upper-lower)/mid. PercentB=(C-lower)/(upper-lower), unbounded. KC(n,a,k): EMA(C,n) +/- k*ATR(a).
- VWMA(n)=sum(C*V,n)/sum(V,n). Session/anchored VWAP=sum(TP*V from anchor)/sum(V from anchor), TP=(H+L+C)/3. US session anchor 09:30 local; crypto session anchor 00:00 UTC. Anchored VWAP starts at the explicitly identified breakout bar, never a retrospectively chosen low. Session VWAP comparisons with historical VWAP require those historical values from the same session; otherwise skip.
- OBV starts at 0; add V when C>C[1], subtract when lower, unchanged close adds 0. ADL increment=((2*C-H-L)/(H-L))*V, zero increment if H=L. CMF(n)=sum(ADL increments,n)/sum(V,n). ChaikinOsc(f,s)=EMA(ADL,f)-EMA(ADL,s).
- ForceEMA(n)=EMA((C-C[1])*V,n). MFI(n): positive and negative sums of TP*V based on sign(TP-TP[1]); MFI=100-100/(1+positive/negative). Equal TP contributes neither. Both sums zero=>50; only negative zero=>100.
- NVI starts 1000; if V<V[1], NVI=NVI[1]*(1+r), otherwise unchanged. EOM=((H+L)/2-(H[1]+L[1])/2)*(H-L)/V; multiplying by a positive scaling constant does not affect its zero-cross signals. Skip V=0. RVOL must use same-session time slots when the rule specifies them.

## Pair models and optimization
- Pair A/B identifiers are fixed in each document. Pair signal series use aligned total-return closes; map entry dollar targets to actual raw tradable prices. Spread direction is always long A / short B; the reverse is not silently added. Formation models/normalization are frozen only when the rule says so. Otherwise rolling inputs update once per daily close, while actual hedge quantities stay fixed.
- OLS residual model includes intercept. A current residual is log(A_t)-alpha-beta*log(B_t); divide by population formation residual std. With an intercept formation residual mean is zero up to numerical error. For frozen normalized-distance pairs, A_norm=A_TR/A_TR_at_formation_start and B_norm likewise; spread=A_norm-B_norm, z=(spread-frozen formation mean)/frozen formation std. Freeze the normalization bases, mean and std until the trading window ends. Select all unordered pairs; distance=sum((A_norm-B_norm)^2); ties alphabetical.
- Six-month windows start at first session opens of January and July; form with data completed before that open; trade until the final session close of June/December, submitting the expiry exit for the next open. Do not open a new pair on the last trading-window session. Earliest first window needs full formation history.
- Engle-Granger choices and AR(1) half-life fit are explicitly given in the individual rules. These are estimation filters, not evidence a given example pair is currently cointegrated. No fitting on future trading-window observations.
- Covariance optimization: COV=sample covariance of aligned decimal daily returns; regularize COV += 1e-6*max(trace(COV)/N,1e-12)*I. Min variance: minimize w.T*COV*w. Equal risk contribution: minimize sum((w_i*(COV*w)_i - (w.T*COV*w)/N)^2)/(w.T*COV*w)^2. Constraints 0<=w_i<=1, sum(w)=1. Deterministic SLSQP from equal weights, ftol=1e-12, maxiter=2000; validate finite weights, sum tolerance 1e-6 and solver success. Otherwise allocate cash and log failure. One eligible asset => weight1. This procedure defines a numerical target, not a guarantee of the global ERC optimum.
- Greedy-correlation selection uses Pearson correlations of synchronized simple daily returns, skips undefined correlations, and follows the documented deterministic sort order. Downside deviation is measured around zero, not around mean return. inverse-risk weights are normalized after dropping invalid/zero-risk observations.
